# MacBook Physical Inspection Checklist

Run through these before committing to purchase. Mark each PASS or FAIL.

## Spec Verification

- [ ] **RAM** — ` → About This Mac → System Report → Memory` → confirm GB matches listing
- [ ] **SSD** — `System Report → Storage` → confirm GB + "Status: Verified"
- [ ] **Serial** — `System Settings → General → About → Serial Number` → matches seller listing + Apple coverage page

## Battery

- [ ] **Cycle count** — `System Report → Power → Cycle Count` → <200 preferred
- [ ] **Condition** — `System Report → Power → Condition` → "Normal" only
- [ ] **Capacity** — Coconut Battery or `system_profiler SPPowerDataType` → ≥80% of design capacity

## Display

- [ ] **Backlight bleed** — open white page fullscreen in dark room, check all four corners
- [ ] **Dead pixels** — scan with solid-color background (black, white, red, green, blue)
- [ ] **Yellowing / coating wear** — common on 3+ year MBPs, cosmetic not functional

## Keyboard & Ports

- [ ] **Every key** — press each, confirm actuation, no stuck keys
- [ ] **USB-C ports** — plug + charge test on both
- [ ] **HDMI / SD slot** — if present, test with known-good cable/card

## Audio

- [ ] **Speakers** — play audio, check both channels, listen for crackle at mid-volume
- [ ] **Mic** — record voice memo, confirm clarity

## Thermal

- [ ] **Sustained load** — 5-min video export in Final Cut / HandBrake, or open 25+ browser tabs + run `stress` in terminal
- [ ] **Throttle check** — screen should NOT dim, fan noise should be proportional, not screaming
- [ ] **Paste age indicator** — if it throttles aggressively on fresh load, thermal paste may be 3+ years old

## Camera

- [ ] **Photo Booth** — confirm image clarity, no smudge on lens

## Warranty Docs

- [ ] **Seller warranty** — written terms from Mr. Mac / dealer showing lifetime coverage + parts contribution %
- [ ] **AppleCare** — check Apple coverage page with serial; confirm remaining months if present
